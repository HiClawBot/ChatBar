# 贡献 / Contributing

先读 [SAFETY.md](SAFETY.md)。给 ChatBar 加任何驱动聊天页面、读取登录态、或代替用户点发送的改动，都不会被接受。

Read [SAFETY.md](SAFETY.md) first. Changes that drive a chat page, read a login session, or send a message for the user will not be accepted.

规划对话贡献代码的方式是回复里的 diff，由 `chatbar apply` 放到新分支。不要让 `main` 被直接改写。

Planner contributions are diffs in the reply. `chatbar apply` puts them on a new branch. Do not write a path that commits onto `main`.
